# orion-81.io

The public preview website for **Orion-81**, a grounded space-combat game made entirely with AI, so that its revenue can hire
graphic designers and software engineers who lost work to AI. The site lets you explore the ships, maps and weapons built so far.

This repository holds only the published website: static files (`index.html`, `css/`, `js/`, `assets/`), served with GitHub Pages
for the domain orion-81.io. It has no trackers, no cookies and no forms.

## Made with AI

**Orion-81 is a completely AI-generated project.** Its own code is by Claude Code (Anthropic), directed by the founder. Ships, maps,
textures and sounds are generated by tools Claude Code wrote, and this website was built the same way. The open-source libraries the
project uses are listed on the site under "Not AI-made".

One item is still open and is shown openly on the site: the licence review of game code that came across from a GPL prototype.
An automated similarity scan ran on 8 Oct 2026, and the expert review of its matches is in progress.
